# 静流 Jingliu 隐私说明

静流是一个本地优先的 Chrome 扩展。它只在用户打开的 X / Twitter 页面中工作。

## 读取的数据

- 当前页面已经载入的公开推文文字
- 推文作者账号
- X 显示的内容标签，例如 `Ad`、`Promoted`、`广告`

静流不会读取私信、密码、Cookie、表单输入，也不会主动抓取没有出现在当前页面里的历史内容。

## 数据处理

作者名单、硬过滤词和平台广告标签全部在浏览器本地判断。只有不能被本地规则直接判断的公开信息流卡片，才会发送到用户在设置页指定的 Jev 接口。

TypeSafe 官方接口为 `https://api.typesafe.ai/v1/systemone`；OpenRouter Jev 接口为 `https://openrouter.ai/api/alpha/decisions`。如果用户填写自定义接口，Chrome 会在保存时单独请求该域名的访问权限。

## 本地存储

过滤偏好、接口地址、模型名称和 API Key 保存在 `chrome.storage.local` 中。MVP 不包含静流账号、遥测、分析 SDK或自建中转服务器。

过滤记录只包含运行时间、处理数量、折叠数量和原因类别；误判反馈只包含来源、动作和原因类别。两者都不保存推文原文、作者或链接，分别最多保留 30 条和 100 条。

规则导出文件不包含 API Key、接口地址、历史记录、反馈记录或推文内容。导入后规则仅载入设置页供用户检查，用户点击“保存设置”后才会写入本地存储。

卸载扩展会由浏览器清除扩展的本地存储。

## 有限使用（Limited Use）

静流对网站信息及用户配置接口所返回信息的使用，遵守 Chrome 应用商店用户数据政策及其中的 Limited Use 要求。相关数据只用于提供或改进用户直接使用的信息流过滤功能，不出售、不用于广告、不转移给无关用途，也不会供人工查看；法律要求、安全处置，或用户明确同意并主动请求支持的情况除外。
