PRIVACY NOTICE

Jingliu privacy notice

Updated September 21, 2026

Product boundary

Jingliu is a Chrome extension that runs in the user's browser. This website provides product information and downloads only. It does not receive posts, rules, or API keys processed by the extension.

Information the extension reads

The extension processes public post text, author identifiers, and platform labels already loaded on the current X page. It uses this information for local rules and semantic decisions the user explicitly configures.

Information the extension does not read

Jingliu does not read X direct messages, passwords, cookies, form input, unopened browsing history, or content from unrelated websites.

External Jev requests

When local rules cannot make a decision, the extension may send the relevant public post text and author identifier directly to the user's chosen TypeSafe, OpenRouter, or compatible custom endpoint. Requests do not pass through a Jingliu server.

Local storage

Filter rules, API keys, model settings, counters, and correction records that do not contain post text are stored in Chrome extension local storage. Chrome handles removal of that data when the extension is uninstalled. Rule backups exported by the user do not contain API keys, endpoint URLs, history, or post content.

Limited Use

Jingliu's use of information received from websites and user-configured APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide or improve the user-facing feed-filtering feature. It is not sold, used for advertising, transferred for unrelated purposes, or made available for human review except when required by law, necessary for security, or requested by the user for support with explicit consent.

Website data

The website currently has no accounts, forms, cloud sync, or analytics service. The hosting platform may process basic access logs required to operate the network, subject to its own policies.

Changes

If Jingliu later adds accounts, cloud sync, a server proxy, or telemetry, this notice will be updated and users will be informed before those features are enabled.

Contact

Privacy questions and support requests can be submitted through GitHub Issues.
