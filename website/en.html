INSTALL THE BETA

Ready in three minutes.

This is a developer beta. Until Jingliu is listed in the Chrome Web Store, Chrome requires you to download the ZIP and load the extracted folder in Developer mode.

Chrome distribution documentation ↗
  1. 1
    Download and extract

    Download the beta ZIP and extract the folder containing manifest.json.

  2. 2
    Open extension management

    Enter chrome://extensions in Chrome and turn on Developer mode.

  3. 3
    Load the folder

    Click Load unpacked and select the extracted Jingliu folder.

  4. 4
    Refresh X

    Open or refresh X. Jingliu starts filtering automatically.

STORES LOCALLY

Rules, API key, counters, and corrections that do not contain post text.
