静流隐私说明

更新日期：2026 年 9 月 21 日

产品边界

静流是运行在用户浏览器中的 Chrome 扩展。官网仅提供产品说明和安装包下载，不接收扩展处理的推文、规则或 API Key。

扩展读取的信息

扩展只处理当前 X 页面已经载入的公开推文文字、作者标识与平台标签，用于执行本地规则和用户主动配置的语义判断。

扩展不会读取的信息

扩展不读取 X 私信、密码、Cookie、表单输入、未打开的历史页面或浏览器中的其他网站内容。

外部 Jev 请求

当本地规则无法确定时，扩展可能把对应的公开推文文字和作者标识直接发送给用户选择的 TypeSafe、OpenRouter 或自定义兼容接口。请求不经过静流服务器。

本地保存

过滤规则、API Key、模型设置、处理数量以及不包含推文原文的纠正记录保存在 Chrome 扩展本地存储中。卸载扩展会由 Chrome 按其机制清理相关本地数据。用户主动导出的规则备份不包含 API Key、接口地址、历史记录或推文内容。

有限使用（Limited Use）

静流对网站信息及用户配置接口所返回信息的使用，遵守 Chrome 应用商店用户数据政策及其中的 Limited Use 要求。相关数据只用于提供或改进用户直接使用的信息流过滤功能，不出售、不用于广告、不转移给无关用途，也不会供人工查看；法律要求、安全处置，或用户明确同意并主动请求支持的情况除外。

官网数据

当前官网不提供账号、表单、云同步或分析服务。托管平台可能基于网络运行需要处理基础访问日志，具体以托管平台政策为准。

变更

如果未来加入账号、云同步、服务器代理或遥测，会在启用前更新本说明并明确告知用户。

联系我们

隐私问题与支持请求可通过 GitHub Issues 提交。
